# JoolzCCTV (TV launcher)
A thin launcher for the JoolzCCTV web app (`src/cctv` in joolay/umbrel-apps). It finds your server (home address, then public) and opens it with `?tv=1`;
the wall, layouts, saved views and sign-in all come from the server, so updates happen there. Hold Red during the splash to change the addresses.
Remote keys: arrows move, OK full screen, Back, Red choose camera, Green next layout, Yellow next view, Blue names, 1-9 jump to a camera.
